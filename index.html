Running the Online Shoe Shopping Website locally

Document type: Developer guide (SOP) · Version 1.0 · Author: John Israel D. Sogello

Purpose. Set up and run the Django project on a Windows computer so a developer can test or continue it.

Prerequisites. Python 3.10 or newer, Git, a PostgreSQL server, and a code editor such as VS Code.

Procedure

  1. Download the source code.
    git clone <repository-url> cd online-shoe-shop
  2. Create and activate a virtual environment.
    python -m venv venv venv\Scripts\activate
  3. Install the dependencies.
    pip install -r requirements.txt
  4. Create an empty PostgreSQL database, then enter its name, user and password in the DATABASES section of settings.py.
  5. Create the tables and an admin account.
    python manage.py migrate python manage.py createsuperuser
  6. Start the server.
    python manage.py runserver
  7. Open http://127.0.0.1:8000/ in a browser. The storefront should load; the admin panel is at /admin/.

Troubleshooting

SymptomLikely causeFix
ModuleNotFoundError: No module named 'django'Virtual environment not activeRun step 2, then step 3 again
OperationalError: could not connect to serverPostgreSQL stopped or wrong credentialsStart the PostgreSQL service and recheck step 4
Port 8000 is already in useAnother program uses the portRun python manage.py runserver 8001

Installing Windows 11, making a LAN cable and sharing a printer

Document type: SOP · Version 1.0 · Author: John Israel Sogello

Purpose. Three everyday technician tasks: install Windows 11 from a USB made with Rufus, make a UTP Ethernet cable, and connect two computers so both can print on one shared printer. The Word file has the full steps and a troubleshooting table.

Part A. Install Windows 11 with Rufus

You need an 8 GB or larger USB drive (it will be erased) and a PC with TPM 2.0 and Secure Boot, or use Rufus’s requirement-removal option.

  1. Download Rufus from rufus.ie and open it with the USB plugged in.
  2. Click the arrow beside SELECT, choose DOWNLOAD, then pick Windows 11, the release, edition, language and x64.
  3. Set Partition scheme to GPT and Target system to UEFI, then click START and confirm. Wait for READY.
  4. On the target PC, press the boot menu key (F12, F2, F10, Esc or Del) and choose the USB drive.
  5. Click Install now, choose Custom: Install Windows only, select the drive, and click Next.
  6. Remove the USB when the PC restarts, finish first-time setup, then run Windows Update and install drivers.

Part B. Make an Ethernet cable

ToolPurpose
Internet cable (UTP)The cable with 4 twisted pairs
RJ45 connectorsPlugs for both ends
ScissorsCut to length, trim wire tips
Cable stripperRemoves the outer jacket safely
Crimping toolPresses the connector onto the wires
LAN testerChecks all 8 wires

Wire order (T568B, both ends for a straight-through cable): 1 white-orange, 2 orange, 3 white-green, 4 blue, 5 white-blue, 6 green, 7 white-brown, 8 brown.

  1. Cut the cable and strip about 2.5 cm of the outer jacket.
  2. Untwist the pairs, straighten the wires and arrange them in the color order above.
  3. Trim the tips flat, leaving about 1.2 cm exposed.
  4. Slide the wires into the RJ45 connector (clip facing down) until they touch the end, then crimp.
  5. Repeat on the other end, then test with the LAN tester. Lights 1 to 8 should flash in order on both units.

Part C. Connect two computers and share a printer

  1. Plug the Ethernet cable into the LAN port of both computers.
  2. Set manual IPv4 addresses: PC1 192.168.1.10 and PC2 192.168.1.11, subnet mask 255.255.255.0.
  3. Set both networks to Private and turn on Network discovery and File and printer sharing.
  4. Test from PC2 with ping 192.168.1.10.
  5. Connect the printer to PC1, install its driver, then open Printer properties > Sharing and tick Share this printer.
  6. On PC2, choose Add device > The printer that I want isn’t listed > Select a shared printer by name, and enter \\192.168.1.10\OfficePrinter.
  7. For automatic printing, set the shared printer as default on both PCs and set the Print Spooler service to Automatic. Keep PC1 and the printer on.
